# Potato Studios

Offizielles Portal und Download-Repository für **Potato Studios**.

## Live-Portal
Die Webseite ist über GitHub Pages erreichbar:
https://leonmeisner1420-source.github.io/potato-studios-web/

## Download & Installation
1. Öffne das Live-Portal oder lade `Potato_Studios.exe` direkt aus diesem Repository herunter.
2. Starte `Potato_Studios.exe` auf deinem Windows-PC.
3. Falls Windows SmartScreen beim ersten Start warnt, klicke auf **Weitere Informationen** und dann auf **Trotzdem ausführen**.

## Projektdateien
* `index.html` – Webseite und Download-Portal
* `Potato_Studios.exe` – Windows-Anwendung für Potato Studios
